## 1. Select text → 问旁注 (replaces the system selection menu)

| Step | Behaviour |
|---|---|
| Long-press | 380ms on a word selects it (optional 8ms haptic). Moving > 8px before that = swipe, cancel. |
| Extend | Keep holding and drag; extend word-by-word. Hit-test = nearest word, vertical distance weighted ×4 (prefer same line). |
| Adjust | After release, two black handles at the ends: 2px bar + 12px dot (start: dot on top, end: dot at bottom), 28px-wide hit area. Draggable. |
| Selection style | Word background `rgba(34,31,27,.16)`. Lines containing the selection are unblurred (blur 0, opacity 1). |
| Block system menu | `-webkit-touch-callout:none`, `user-select:none` on the page, `preventDefault` on `contextmenu` and `selectstart`. Native shell must also disable the edit menu (iOS `UIEditMenuInteraction` / `canPerformAction` → false; Android `ActionMode` callback returns false). |
| Floating button | Black pill, 40px tall, padding `0 16px 0 14px`, radius 20, Noto Sans SC 500 13.5px `#fff`, 5px white dot + `问旁注`. Shadow `0 12px 26px -12px rgba(0,0,0,.5)`. Placed 56px above the selection's top line, centred on the selection, clamped to `[72, W−72]`; if top < 84px, place 20px below the bottom line. In: opacity 0→1, `translate(-50%,6px) scale(.96)` → `translate(-50%,0) scale(1)`, 180/240ms. Hidden while dragging. |
| Tap button | Clear selection → open Agent drawer → put the selected text as an **attachment card above the input** → focus input after 460ms. |
| Cancel | Any tap on the page, or a left swipe (which also opens the drawer). |

**Attachment card** (inside the drawer, directly above the input):
- `#fff`, radius 16, `box-shadow:0 0 0 1px rgba(0,0,0,.06)`, padding `10px 4px 11px 14px`, margin-bottom 8.
- Label `选中的文字 · 第 N 章`: IBM Plex Sans 500 9.5px, letter-spacing .18em, uppercase, `rgba(0,0,0,.45)`.
- Quote: Newsreader 13.5/1.55 `#111`, wrapped in “ ”, clamp 3 lines.
- × button 36×36, icon 12px `rgba(0,0,0,.45)` → removes the attachment.
- **当前句 and 选中的文字 share one slot: directly above the input, never both.** Opened by left swipe → 当前句 picker card (white, radius 16, picker height 132px) sits there. Opened via 问旁注 → the attachment card replaces it. Removing the attachment (×) brings the 当前句 card back. Closing the drawer clears the attachment, so the next left swipe always shows 当前句.
- While attached: input placeholder `就这段文字提问`; quick chips switch to selection chips (`解释这段` / `这里有什么隐喻` / `和前文有关联吗`).
- On send: the message quote = attachment text (falls back to the current sentence); attachment is cleared.

## 2. Settings sheet — entry and direction

- **No persistent buttons on the reading page.** No `Aa` button, no bottom toolbar, no top bar. Also removed: the small grey scroll indicator on the right edge.
- **Open**: tap anywhere in the **top 30%** of the reader.
- **Direction**: the sheet **rises from the bottom**. Leather surface (same as the word drawer), radius `18px 18px 0 0`, padding `4px 22px 30px`, max-height 44%, shadow `0 -14px 30px -14px rgba(0,0,0,.5)`. Grab handle (36×4, `rgba(242,234,217,.25)`) at the top.
- Motion: `translateY(104%) → 0`, open 330ms / close 250ms, `cubic-bezier(.22,.9,.3,1)`.
- **Close**: tap outside the sheet (full-screen transparent scrim) or tap the handle.
- While open, page gestures (long-press, swipe) are disabled.

Tap priority on the page:
1. Selection exists → clear it.
2. Sheet / drawer open → close it.
3. Tap in top 30% → open settings.
4. Tap on a word → word drawer.

## 3. New setting: 聚焦模糊 toggle (first row)

| | |
|---|---|
| Key | `blurOn` (Settings table), default `true` |
| Row | min-height 58, title `聚焦模糊` Noto Sans SC 500 14px `#f2ead9`; subtitle 11px `rgba(242,234,217,.5)`: on `中央清晰，上下渐隐模糊`, off `已关闭 · 全文清晰` |
| Switch | 46×28 track, 22px knob. On: track `#f2ead9`, knob `#2c2620`, x 18px. Off: track `rgba(242,234,217,.16)`, knob `rgba(242,234,217,.7)`. 220ms. |
| Off | Every line `filter:none; opacity:1`; **top and bottom fade masks hidden** (opacity 0, 300ms). Nothing on the page is blurred. 清晰带 / 模糊强度 / 整句模式 rows dim to opacity .32 and ignore input. |
| On | Original focus-band formula with current `focusPct` / `blurMax`. |
| Engine | Reader engine reads `blurOn` from the settings store; when false skip per-line blur work entirely. |

Order of rows: 聚焦模糊 · 清晰带 · 模糊强度 · 整句模式 · 字号.
