# M2–M4 implementation notes (2026-09-26)

M2–M4 were built directly on the M1 core, one milestone at a time. This note records where the spec was silent or where the build differs from it, so a reviewer can check each choice.

## Dictionary (M2)

- **One lookup path on iOS and web.** `dict.db` (5.4 MB) is read into sql.js in memory on both platforms, instead of the native plugin on iOS. Lookups are synchronous and take well under 1 ms, with no native-bridge round trip inside the 100 ms tap budget (R-04). `user.db` still uses the native plugin on iOS.
- **Schema beyond the README.** `entry(word, phonetic, pos, gloss)` holds the default reading. Two additions: a `sense(word, cls, pos, gloss)` table for the other parts of speech, and a `kind` column on `forms` (the class an inflection implies: *carried* → verb, *boats* → noun). Licence notices are stored in a `meta` table.
- **Inflections resolve to the lemma.** ECDICT's own entries for *was* or *went* are only "be的过去式". A short `PREFER_EXACT` list keeps words that are usually nouns in these novels (*ground*, *wound*, *leaves* …) as themselves.
- **Choosing the sense (one line per the spec).** The choice goes, in order:
  1. The inflection class.
  2. A one-word context cue: `to`/a modal/a subject pronoun before the word means verb; a determiner before a verb-default word means noun.
  3. The entry's default, chosen at build time from POS votes counted over the three bundled books.
  4. Then the fullest line, with ECDICT's line order breaking ties. For example, *summer* → 夏季 and *look* → 看.
  A handful of function words have a fixed class (*can* → aux, *like* → prep).
- **American IPA** from ipa-dict `en_US`, normalised to learner-dictionary style: `r`/`l` for `ɹ`/`ɫ`, `ʌ` for stressed `ə`, `ɚ` for unstressed `ɝ`, and no stress mark on one-syllable words.
- **Coverage.** 99.8% of the 198k word tokens in the bundled books resolve; names mid-sentence are excluded. The build fails below 98%.
- **The drawer shows the lemma** as its headword ("went" → *go*).

## Reader (M2)

- **Footnotes are per occurrence.** Each footnote uses the sense for that occurrence's own class. They appear under the open word as soon as the drawer finishes opening (as in `fig-4a-drawer.png`). A Set of the seen lemmas' surface forms pre-filters words, so only candidates go through a full lookup.
- **The drawer is a gap in the engine.** `openGap` inserts a host after the tapped line. While the drawer animates, its height is fed to the engine every frame, so lines below are painted at their real positions. Virtualisation is paused while the drawer is open, and a resize closes the drawer rather than mis-measuring.
- **Layout of the drawer.** Save sits below the definition and the definition wraps, matching `fig-4a-drawer.png` rather than a single-line layout. The drawer sits above the fade masks (z-index 3), so one opened low on the screen is not faded.

## Home, import, transition (M3)

- **Import parses the whole book at once.** Parsing *A Farewell to Arms* (89k words) takes about 70 ms on a desktop, so there is no separate "first chapter first" stage. The H-03 e2e test measures file → readable text at under 3 s.
- **TXT import:**
  - Paragraphs are split on blank lines; hard-wrapped lines are joined.
  - Headings like `CHAPTER IV`, `Part Two` or `XII` start chapters.
  - Project Gutenberg headers and licences are dropped.
  - A book with no headings is cut into sections of about 2,500 words.
  - Non-UTF-8 files get a plain-language error.
- **Duplicate imports** (same title and author) open the existing book instead of adding a copy.
- **Covers:**
  - Bundled books: resized JPEGs in `public/covers/`, made at build time.
  - Imported EPUBs: a 360 px JPEG data URL, kept small because the web database is saved whole.
- **Flight timing.** The reader mounts after the expand phase (460 ms), so its layout work cannot stall the animation. Going back reloads the shelf first, so the flight lands where the book now is.
- **Chinese UI font is PingFang SC** (the system font on iOS and macOS), with Noto Sans SC as a fallback in the stack. Bundling Noto Sans SC would add about 10 MB and change nothing on the target platforms.

## Polish (M4)

- **TOC (R-10)** uses the same leather sheet as settings. The current chapter is marked with a vermilion dot, and its text is lifted to `#ea7a62` for 5:1 contrast on leather.
- **Swipe-to-delete (H-05)** reveals 删除; a confirmation dialog follows. Deleting cascades to chapters, position and Lookup rows. An empty shelf offers the three bundled books back.
- **Metrics (task 23)** are a local `metric` table (sessions, lookups, drawer closes with re-scroll within 10 s). Exporting from Home (导出内测日志) goes to the iOS share sheet, or Web Share / a download on the web.
- **Mobile web offline** uses a generated precache service worker. It was verified by stopping the server and reloading in Chromium (e2e) and in Safari on the iOS simulator.
- **App icon:** the focus band as three states of the same lines, rendered from `design/icon/icon.html`.
