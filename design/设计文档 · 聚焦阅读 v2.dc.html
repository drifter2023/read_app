聚焦阅读 · UI 设计规范

Annotated UI specification · 图文对照版

v2 · 2026-09-22 · 源文件 聚焦阅读 App.dc.html · 画板 402 × 812 @1x · 截图取自实现原型

产品定义：一个把注意力当作第一资源的英文阅读器。屏幕中央是一条固定的清晰带，其余文本按距离衰减；点任意单词从纸面裂开一条抽屉给出释义，查过的词在词下留一枚 9px 汉字脚注。

怎么读这份文档：每个界面一张实机截图，图上的红色编号对应右侧标注清单，清单里给出该部件的字号、颜色、间距与行为。章节末的表格是可直接落地的参数。第 11 节是给 Agent／自动化工具的机读附录（JSON），字段与正文一一对应。

栅格与尺寸：主页左右留白 24px（7b 为 20px），阅读页 34px（1c 32px）；分节用 1px 细线而非卡片描边；可点区域最小 44px；底部标签栏 74px（7b 为距底 26px 的 60px 悬浮胶囊）。

对比度：10–13px 小字不低于 4.5:1（浅底 62%、深底 60% 透明度），大字号标题与数字放宽到 3:1；9px 汉字脚注用 500 字重补偿字号。

6 · 动效规范

全 App 只用一条曲线：cubic-bezier(.42,0,.58,1)（拟物 iOS）。打开书的飞行层四段时序：抽出 220 → 展开 460 → 封面淡出 300 → 正文淡入 320ms，阴影固定 0 18px 40px rgba(0,0,0,.5)。

书展开满屏460msleft / top / width / height → 0,0,402,812
封面淡出 → 正文淡入300 / 320msopacity 交叉
