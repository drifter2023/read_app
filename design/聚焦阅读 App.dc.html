1预留 feature · 聚光夜读（强景深 + 自动带读，可调速）
交互逻辑要点
1. 焦点带是屏幕坐标，不是文档坐标
焦点带永远在视口垂直中央（约 3 行高）。滚动时不移动它，只重新计算每一行相对它的距离。
2. 按「行」而不是按「段」计算
正文需要拆成可测量的行元素（或用 Range 逐行测量），每行拿到 d = |行中心 − 视口中心|。
3. 一条衰减曲线驱动全部视觉
先减去焦点带半高得到 x = max(0, d − half)，再由 x 映射出模糊、透明度、缩放。x=0 的行绝对清晰。
4. 滚动帧内只写样式，不触发布局
滚动监听用 passive + rAF 节流；行位置缓存一次（仅在字号/窗口变化时重算），帧内只写 filter / opacity / transform。
5. 上下留白 ≥ 半屏
首行和末行也要能走到中央，容器上下各留 45vh 内边距。
6. 可访问性兜底
长按 / 双击暂停模糊；prefers-reduced-motion 时用透明度代替模糊；选中文字时全文恢复清晰。
