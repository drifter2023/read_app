MVP technical architecture · v0.2 · 2026-10-25

聚焦阅读 · 技术架构

首页 + 阅读页。词典、字体和书都在设备上。网络只有两处例外：读者自己的 DeepSeek 钥匙（语法水滴、旁注提问），以及自己的 Worker POST /api/fetch（链接导入）。四层结构；焦点带渲染管线与查词链路仍是重点。配套文档：MVP 设计与范围。

焦点带渲染管线
每帧 ≤ 4ms 预算
scroll→ rAF 合帧→ 取可见行 ±1 屏→ t = clamp((d − half) / ramp)→ 整句 +0.18→ blur 量化 0.5px→ 差量写 filter / opacity
行表在分行时一次算好（每行的 top 和 height），滚动时只做数值比较，不读 DOM 布局。降级路径：关掉逐行 blur，改成上下两层静态 backdrop 模糊加逐行 opacity。

关键链路

朱红框 = 性能关键点
F1
导入
选择文件→ 复制进 files/→ Worker 解析元数据 + 首章→ 写 Book + Chapter[0]（≤ 3s 可读）→ 书架出现新行→ 后台解析其余章节
F2
打开书
点书架行→ 记录封面几何位置→ 飞行层：抽出 220 · 展开 460→ 同时：读 Position、挂载章节、分行→ 封面淡出 300 · 正文淡入 320→ 锚点句落在焦点带
F3
查词
点击→ 命中测试：词 + 句→ lemma 还原→ LRU → dict.db（≤ 100ms）→ 抽屉 330ms 展开 · 入屏补滚动→ 写 Lookup · seen += lemma→ 关闭 250ms → 全书同词挂 9px 注 · 撤回则去掉
F4
语法
清晰带句末水滴→ 点按→ DeepSeek（读者的钥匙）→ 抽屉：译文在上，语法在下
F5
旁注
左滑，书页留约 60px→ 当前句或问旁注占同一槽→ 发送后才请求 DeepSeek→ 会话按书存在本机，无工具、不跨书
F6
链接导入
粘贴链接并提交→ POST /api/fetch（只取公开页，不存 URL）→ Readability 抽出正文→ 写入 Book，与文件导入同一条书架
F7
主题
首页胶囊 纸白 / 夜读→ 写入 prefs→ 首页换 7b 色，阅读页换 1c 色→ 边距与字号不变；夜读才出现带读条
